# GUI Gopher

A native macOS Gopher client written in Objective-C and AppKit.

## Build

Open `GUIGopher.xcodeproj` in Xcode and run the **GUIGopher** scheme.

Enter a `gopher://` address in the toolbar (or a hostname such as `gopher.floodgap.com`) and press Return. The client parses Gopher menus, opens text documents, prompts for type 7 searches, saves binary and image items, and keeps back/forward navigation history. Use the star in the toolbar to add or remove a bookmark; bookmarks persist between launches and appear in the sidebar alongside the current session's history.
